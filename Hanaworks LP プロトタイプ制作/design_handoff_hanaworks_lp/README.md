# Handoff: hanaworks LP（ランディングページ）

## 概要
hanaworks向けのLP（ランディングページ）デザイン。PhotoshopカンプPDFを参照し、ヒーロー背景画像・お問い合わせフォーム・料金プラン・FAQ等を含む1ページ構成のLPプロトタイプ。「見た目だけでなく機能（予約システム・料金シミュレーターなど）も一括提供する」という訴求を軸にしている。

## このファイルについて
`Hanaworks_LP_prototype.html` は**デザイン参照用のHTMLプロトタイプ**であり、そのまま本番コードとして流用するものではありません。レイアウト・配色・タイポグラフィ・コピー・インタラクションの意図を伝えるための参照実装です。実装時は、対象プロジェクトの環境（Next.js / 素のHTML+CSS / 他フレームワーク等、既存のスタックがあればそれに合わせる。なければ適切なものを選定）で、このデザインを再現してください。

## Fidelity
**Hi-fi（高精度モックアップ）**。色・フォント・余白・コピーはほぼ最終決定に近い状態です。ピクセルパーフェクトに近い再現を目指してください。ただし以下は元PSDから未確定/仮の要素です:
- ヒーロー画像・お悩みセクション画像・CTAバナー画像は差し替え可能なプレースホルダーとして扱われていますが、本ハンドオフには実際に使用された最終画像を同梱しています（`assets/`）。
- お問い合わせフォームはフロントエンドのみのモック送信（実際のAPI送信・メール送信は未実装）。

## 画面構成（1ページ・セクション単位）

### 1. ヘッダー（sticky）
- 背景: `#f4f1ea` の92%不透明+backdrop-blur、下線 `rgba(14,35,65,0.1)` 1px
- 左: ロゴ「hanaworks.」Noto Serif JP 700、`.`のみ `#f8c974`
- 右（PC、881px以上）: ナビリンク（サービス/料金/実績/FAQ）+ CTAボタン「まずは相談する」（背景`#0e2341`、文字`#f4f1ea`）
- 880px以下: ナビは非表示になりハンバーガーメニューに切り替わる（3本線、クリックでフルスクリーンのオーバーレイメニュー表示、背景`#0e2341`）

### 2. ヒーロー
- 背景画像: `assets/lp-hero.jpg`（`background-size:cover; background-position:center`）
- PC（881px以上）: `min-height: clamp(560px, 100vh, 880px)`
- モバイル（880px以下）: 画像の縦横比を保持するため `aspect-ratio: 16/9` に切り替え（画像が途切れないようにするため）。テキストブロックの幅も画像左上の余白（画像内の白いエリア）に収まるよう `max-width: 56%` に縮小し、フォントサイズも `clamp(12px, 3.4vw, 17px)` まで縮小
- キャッチコピー（H1）: Noto Serif JP 700、色 `#0e2341`、「まとめて」のみオレンジ `#e0862e` で強調
  - コピー: 「集客できるLP＋（改行）業務を効率化する「機能」、（改行）まとめて作ります。」
  - PC時は2行目「業務を効率化する「機能」、」を1行に収めるため `white-space: nowrap` + フォントサイズ調整

### 3. お悩みセクション（背景 `#f4f0e9`）

### 4. 差別化セクション（背景画像 + 白カード）

- その上に `#f4f0e9` ベースの半透明グラデーションのスクリム（上下は濃く55%、中央は薄く15%）
- 中央に白背景カード（`border-radius: 28px`、`box-shadow: 0 20px 44px rgba(14,35,65,0.1)`）
- テキスト:「他のLP制作者との最大の違いは「機能」です。見た目のきれいなデザインというだけでなく、「予約システム」、「料金シミュレーター」など集客に必要な仕組みをLPにそのまま組み込みます。」（「機能」のみ `#c99a3f` 太字）

## インタラクション・挙動
- ハンバーガーメニュー: クリックで開閉、リンククリックで自動的に閉じる
- FAQアコーディオン: 1問ずつ開閉（複数同時展開可、各々独立）
- お問い合わせフォーム: `onSubmit`で`preventDefault`し、送信完了状態に切り替え（実際のAPI送信は未接続）
- レスポンシブ切り替え: `window.matchMedia('(max-width: 880px)')` を使い、880px以下でナビ・ヒーローのレイアウトを切り替え（JSでの状態管理、CSSメディアクエリではない実装だった点に注意。実装時はCSSのメディアクエリ/コンテナクエリで問題ありません）
